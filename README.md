# جداولي — نسخة أندرويد تعمل بدون إنترنت

تحويل لموقعك (PHP + SQLite) إلى تطبيق مستقل: كل البيانات تُحفظ على الهاتف (IndexedDB)، ولا حاجة لخادم أو إنترنت.

## جرّبه فوراً على الكمبيوتر
افتح `www/index.html` في Chrome. (للتجربة فقط؛ التخزين هناك خاص بالمتصفح.)

## الحصول على ملف APK

### الطريقة 1: بدون تثبيت أي شيء (GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد (بما فيه `.github`).
2. من تبويب **Actions** شغّل **Build APK** (أو يعمل تلقائياً عند الرفع).
3. بعد دقائق نزّل الملف من **Artifacts → jadawli-apk** وثبّته على هاتفك (فعّل «التثبيت من مصادر غير معروفة»).

### الطريقة 2: Android Studio
```
npm install
npx cap add android
npx capacitor-assets generate --android
npx cap sync android
npx cap open android      # ثم Build ▸ Build APK(s)
```
المتطلبات: Node 22+، JDK 21، Android Studio.

## تخصيص
- اسم التطبيق ومعرّفه: `capacitor.config.json` (غيّر `appId` إلى معرّف خاص بك قبل النشر).
- بعد أي تعديل في `www/` شغّل `npx cap sync android`.

## ما تغيّر عن الموقع الأصلي
**محفوظ كما هو:** الجداول والأعمدة (نص، صح/خطأ، قائمة، رقم، مدة، تاريخ، وقت)، الأعمدة المفتاحية، القوالب، توليد جدول شهري، أوضاع العرض الثلاثة، تمييز اليوم، الوضع الداكن، وشاشة الدخول المموّهة (Server ← OK ← running).

**أُضيف أو حُسّن:**
- حفظ تلقائي لكل تعديل (بدون زر حفظ).
- مزامنة وضعي الجدول والبطاقات (في الأصل كانا نسختين منفصلتين).
- إحصائيات لكل جدول: نسبة الإنجاز، أطول سلسلة وسلسلة اليوم، مجاميع الأرقام والمدد، توزيع القوائم.
- نسخ احتياطي واستعادة (JSON) وتصدير الجدول إلى CSV.
- تذكير يومي بالإشعارات (داخل التطبيق فقط).
- إعادة تسمية سطر أو عمود تنقل بياناته معه (في الأصل كانت تُفقد).
- إضافة عدة أسطر دفعة واحدة، ونسخ بنية الجدول، وتصفح البطاقات بالسحب.
- الخط والمكتبات مضمّنة محلياً (الأصل كان يحمّل الخط وSortable من الإنترنت).
- رمز PIN يختاره المستخدم بدل الحساب الافتراضي `admin / admin123`.

**أُزيل لأنه لا معنى له بدون خادم:** إدارة المستخدمين والصلاحيات (التطبيق لجهاز ومستخدم واحد).

## ملاحظات
- القفل يخفي الواجهة فقط ولا يشفّر البيانات.
- البيانات على الجهاز؛ خذ نسخة احتياطية من الإعدادات قبل حذف التطبيق أو تغيير الهاتف.
- الـ APK الناتج «debug» ويصلح للتثبيت الشخصي. للنشر على Google Play تحتاج توقيع Release.
