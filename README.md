# جداولي — نسخة أندرويد تعمل بدون إنترنت

تحويل لموقعك (PHP + SQLite) إلى تطبيق مستقل: كل البيانات تُحفظ على الهاتف (IndexedDB)، ولا حاجة لخادم أو إنترنت.

## جرّبه فوراً على الكمبيوتر
افتح `www/index.html` في Chrome. (للتجربة فقط؛ التخزين هناك خاص بالمتصفح.)

## الحصول على ملف APK

### الطريقة 1: بدون تثبيت أي شيء (GitHub Actions)
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (بما فيه `.github`).
2. من تبويب **Actions** شغّل **Build APK**.
3. بعد دقائق نزّل **Artifacts ← jadawli-apk** وفك الضغط، ستجد:
   - `jadawli-full.apk` — **النسخة الكاملة** (فيها محرك المنبهات الأصلي: رنين مع إغلاق التطبيق، وشاشة تنبيه فوق القفل، وتبديل الأيقونة).
   - `jadawli-safe.apk` — **النسخة الآمنة** (كل الميزات عدا المنبهات الفعلية)، تُبنى دائماً.
   - `full-build.log` و`patch.log` — يظهران لتشخيص أي مشكلة.
4. ثبّت الكاملة. إن لم تُبنَ (يظهر ⚠️ في ملخص التشغيل) أو لم تعمل على هاتفك فثبّت الآمنة وأرسل السجل.
   النسختان بنفس المفتاح فتُثبَّت إحداهما فوق الأخرى دون فقدان البيانات.

### الطريقة 2: Android Studio
```
npm install
npx cap add android
npx capacitor-assets generate --android
npx cap sync android
npx cap open android      # ثم Build ▸ Build APK(s)
```
المتطلبات: Node 22+، JDK 21، Android Studio.

## نقل بياناتك من الموقع القديم
1. حوّل قاعدة البيانات إلى ملف JSON: `python tools/convert_db.py database.sqlite out.json` (أو أضف أرقام الجداول في آخر الأمر لتصدير جداول محددة). لا تُصدَّر بيانات المستخدمين وكلمات السر.
2. انسخ الملف إلى الهاتف، ثم من التطبيق: **الإعدادات ← استيراد نسخة احتياطية** (أو زر «استيراد بياناتي» في الشاشة الأولى).
3. إن كان في التطبيق بيانات فسيسألك: **إضافة** إلى الموجود (يُعاد ربط الخلايا تلقائياً) أو **استبدال**.

> **تنبيه خصوصية:** ملفات `database.sqlite` وملفات JSON الناتجة تحتوي بياناتك الشخصية. لا ترفعها إلى مستودع GitHub عام (مُدرجة في `.gitignore`).

## المرحلة 2: المنبهات
- منبهات متعددة بعناوين وأيام، ويمكن ربط أي منبه بـ **جدول وعمود**: يبدأ عدّاد تنازلي في الإشعار قبل الموعد (30 دقيقة افتراضياً)، ثم عدّاد تصاعدي بعده (+) إن لم تُسجَّل القيمة، مع إعادة التنبيه كل 10 دقائق حتى 3 مرات. كل هذه الأرقام قابلة للتغيير لكل منبه.
- شاشة التنبيه **بملء الشاشة** (حتى فوق القفل) تتيح كتابة القيمة مباشرة؛ وعند تسجيلها يتوقف كل شيء.
- الربط يتبع جدول الشهر الحالي تلقائياً (بالاسم الأساسي)، ولا يُربط بجدول شخص آخر.
- **التمويه**: تظهر شاشة القفل كتطبيق منبّه حقيقي (الضغط المطول على أيقونة الساعة يفتح الجداول)، ويمكن تبديل أيقونة التطبيق واسمه إلى «المنبّه» من الإعدادات.
- المنبهات تُجدوَل بنظام المنبهات في أندرويد، فلا يبقى التطبيق يعمل في الخلفية ولا يستهلك رامّاً.
- الكود الأصلي في `native/` ويُدمج عبر `tools/patch_android.py`؛ واختبار منطق الجدولة في `native/test/SchedTest.java`.

## الجديد في المرحلة 1
- **ملاحظات بثلاثة أنواع**: لكل يوم (في البطاقة، أو بالضغط على اسم اليوم في الجدول)، ولكل جدول، وعامة. وتدخل في النسخ الاحتياطي.
- **مكتبة 39 قالباً** (ديني، طلاب، موظفون، الأم والمنزل، صحة، عامة) من شاشة «الجداول ← القوالب».
- **ساعة دائرية** لاختيار الوقت والمدة بنظام 24 ساعة، بلا AM/PM داخل الجداول والبطاقات.
- **عرض أعمدة ديناميكي**: تلقائي بحسب المحتوى، واسحب حافة العنوان في الجدول لتغييره (يُحفظ).
- **تصدير PDF بنص حقيقي** في صفحة واحدة (A3، وA2 تلقائياً عند الحاجة) ومشاركته.
- **حذف كل البيانات** يتطلب تأكيداً ثم لغزاً (ناتج ضرب أو كلمة تكتبها).
- **حذف رمز الدخول** وتغييره بعد إدخال الرمز الحالي.
- تصميم جديد: حقول بخط سفلي فقط، وتوهّج خفيف بلون الإطار عند التحديد وحول بطاقة اليوم.
- تجهيز للمزامنة: معرّف ثابت لكل جدول، ووقت آخر تعديل لكل خلية، ومعرّف للجهاز.

## تخصيص
- اسم التطبيق ومعرّفه: `capacitor.config.json` (غيّر `appId` إلى معرّف خاص بك قبل النشر).
- بعد أي تعديل في `www/` شغّل `npx cap sync android`.

## ما تغيّر عن الموقع الأصلي
**محفوظ كما هو:** الجداول والأعمدة (نص، صح/خطأ، قائمة، رقم، مدة، تاريخ، وقت)، الأعمدة المفتاحية، القوالب، توليد جدول شهري، أوضاع العرض الثلاثة، تمييز اليوم، الوضع الداكن، وشاشة الدخول المموّهة (Server ← OK ← running).

**أُضيف أو حُسّن:**
- حفظ تلقائي لكل تعديل (بدون زر حفظ).
- مزامنة وضعي الجدول والبطاقات (في الأصل كانا نسختين منفصلتين).
- إحصائيات لكل جدول: نسبة الإنجاز، أطول سلسلة وسلسلة اليوم، مجاميع الأرقام والمدد، توزيع القوائم.
- نسخ احتياطي واستعادة (JSON) وتصدير الجدول إلى CSV.
- إعادة تسمية سطر أو عمود تنقل بياناته معه (في الأصل كانت تُفقد).
- إضافة عدة أسطر دفعة واحدة، ونسخ بنية الجدول، وتصفح البطاقات بالسحب.
- **مجموعات ديناميكية**: من «تعديل الجدول ← المجموعات» تنشئ مجموعة وتسمّيها وتحدد أعمدتها؛ فتظهر أعمدتها معاً (حتى لو كانت متفرقة) في البطاقات والجدول والإحصائيات.
- **بطاقة اليوم** هي الافتراضية للجداول العريضة (أكثر من 8 أعمدة)، مع عدّاد إنجاز لليوم، وأزرار + و − للأعمدة الرقمية.
- في عرض الجدول يُخفى عمودا التاريخ واليوم المكرران ويُختصر عنوان السطر (مثل «01 خميس»).
- **الشهر الجديد بضغطة**: إذا لم يوجد جدول للشهر الحالي تظهر لافتة تولّده بنفس بنية آخر جدول (بما فيه تعديلاتك عليه)، مع اسم تلقائي.
- أعمدة «المدة» تقبل `1:30` أو رقماً مجرداً (يُحسب كدقائق).
- الخط والمكتبات مضمّنة محلياً (الأصل كان يحمّل الخط وSortable من الإنترنت).
- رمز PIN يختاره المستخدم بدل الحساب الافتراضي `admin / admin123`.

**أُزيل لأنه لا معنى له بدون خادم:** إدارة المستخدمين والصلاحيات (التطبيق لجهاز ومستخدم واحد).

- القفل يخفي الواجهة فقط ولا يشفّر البيانات.
- البيانات على الجهاز؛ خذ نسخة احتياطية من الإعدادات قبل حذف التطبيق أو تغيير الهاتف.
